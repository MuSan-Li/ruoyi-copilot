# RuoYi Copilot v0.0.1

基于 Vue 3 + Vite 的 Copilot 前端 UI，对接 RUOYI-AI后端（会话、模型、工作区、流式对话）。

## 技术栈

- Vue 3 (`<script setup>`)
- Vite 7
- 原生流式对话（SSE / fetch stream）

## 开发

```bash
npm install
npm run dev      # http://127.0.0.1:5174
npm run build    # 生产构建
npm run preview  # 预览构建产物
```

后端代理默认指向 `http://localhost:6039`，见 `vite.config.ts`。

## 完整交互轨迹导出（暂未开放）

当前界面暂不展示「导出完整轨迹」入口，相关导出工具与测试保留。导出格式为 UTF-8 JSONL，读取后端持久化账本，包含当前会话的所有运行轮次，而非界面最近 2,000 条消息：

- `manifest`：格式版本、会话 ID、导出时间和各类记录数量。
- `session` / `run`：模型配置、原始需求、计划、审批、运行状态等原始快照。
- `message`：用户输入、模型返回、工具参数、完整工具结果及持久化元数据。
- `event`：各轮执行、审批、失败、恢复等原始事件，按运行分组、序号升序。
- `end`：完成标志与计数，可用于检测文件截断。

每行均为独立 JSON；`message` 和 `event` 的 `data` 保留接口原始字段，不以摘要替代正文。模型未返回或服务端未持久化的信息无法由导出补造。任务尚在执行、审批或暂停时会提示先完成或取消；读取失败、序号缺失或导出期间会话变化时不会下载半成品。

若服务端将超长正文转存为外置制品，或已省略超长独立思考，当前导出会明确拒绝，避免把制品指针或摘要冒充完整正文。此类会话需要连同服务端制品另外打包；本次两轮复测需分别检查是否存在这种情况。

当前界面不再提供「验收方式」选择，接口仍保留验证归属字段以兼容已有会话。

JSONL 是原始轨迹，可能包含源码、文件路径与工具返回内容。对外提交前请检查其中的密钥或个人数据；如有必要脱敏，应保留脱敏说明与本地原件。
